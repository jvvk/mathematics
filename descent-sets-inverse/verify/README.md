# Supplement to “Descent sets of a permutation and its inverse: almost every pair occurs”

This archive contains the source snapshot and reproducible finite checks for the
7 October 2026 revision. No third-party point-set database is needed.

## Formal proofs

`../lean/` contains the complete local import closure for the density and alternating
permutation theorems, plus pinned Lean/Mathlib dependencies. See `../lean/README.md`.

    cd lean
    lake exe cache get
    lake build LeanProofs
    lake env lean CheckClaims.lean

Expected: `Stanley.Alt.stanleyGF`, `Stanley.Alt.g_asymptotics`,
`Stanley.Alt.g_asymptotics'`, and `Stanley.Density.density_ratio` all have only
`propext`, `Classical.choice`, and `Quot.sound` as axiom dependencies. The
density coefficient is 6. Both asymptotic statements are unconditional and
use the actual permutation count and Euler-number sequence.

## Computations

Python 3.9 or later, standard library only. Run from this directory:

    python3 computations/verify.py examples
    python3 computations/verify.py words 16
    python3 computations/verify.py brute
    python3 computations/verify.py pairs 13
    python3 computations/verify.py maxima 14
    python3 computations/verify.py samples
    python3 computations/series.py

Saved output is in `results/`. Commands fail with a nonzero exit status if an
assertion fails. Use Python without `-O`: assertions are part of the checks.

- `examples`: verifies both newly illustrated row words, their common shape,
  the inverse-RSK permutation's two descent sets, and the missing partition
  (3,3) in the support of the ribbon with composition (1,2,3).
- `words 16`: checks 339,296 row words generated by the two construction rules
  for all allowed parameters and descent sets through n = 16.
- `brute`: enumerates permutations for n = 2 through 9 and checks every pair
  certified by the construction against the actual pair set.
- `pairs 13`: constructs the SYT shape-support bitsets by the row-word dynamic
  program and compares their intersections with the dominance-interval
  intersections for every ordered pair. It checks 4^(n-1) pairs at each n,
  rather than comparing totals alone. The f(n) values are
  1, 2, 6, 22, 94, 426, 1938, 8724, 38724, 169438, 731390, 3119052, 13162228.
  The output also gives gaps in individual supports (4/32 at n = 6,
  544/1024 at n = 11) and the strata used in the paper's table.
- `maxima 14`: checks every diagonal multiplicity through n = 14. For n >= 4
  the two alternating sets alone maximise it, and the second value is at
  most two thirds of the maximum. For n <= 8 it also compares with direct
  permutation enumeration. It checks the stated local maximum 1808 and
  largest neighbour 1751 at n = 11.
- `samples`: uses `random.Random(11)`, consuming bits in the recorded order
  n = 12,13,20,50,100,200,400, with 20,000 pairs per size. It records counts and
  95% Wilson binomial intervals for failure probabilities. These are empirical
  estimates, not proofs of an asymptotic rate. At n = 400 there are 11 failures,
  with interval approximately [0.000307, 0.000985].
- `series`: computes the generating function through n = 160 using exact
  rational arithmetic, reports the asymptotic ratios, and prints the matching
  brute-force counts through n = 9.

The dynamic program builds a Young diagram one entry at a time. Its state is
the current partition and the row of the last entry; the next descent bit
specifies whether the next entry goes to a lower row. Nonnegative counts are
summed by final shape. Two descent sets occur together exactly when their
shape supports intersect, by RSK. Dominance intervals are enumerated directly
over partitions, independently of any implementation of lattice joins.

`SHA256SUMS` identifies the source and saved-output snapshot. The Lean snapshot
also records its original source commit and individual file hashes.

## Joint-multiplicity continuation, 7 October 2026

The Lean archive now also includes the unconditional character inner-product
identity for the actual joint multiplicities, Cauchy-Schwarz, existence of a
diagonal maximum, and the equivalence reducing Gessel's bound to the diagonal.
The growth-limit proof and kernel-checked multiplicity controls are included.
The conjectures themselves remain unproved. The finite Python results above
were unchanged and were not rerun for this formalisation continuation.

Rate computations (Remark 3.4): computations/gr_fail.cpp computes, in long double, the probability
that the cross-dominance condition fails for two independent uniform compositions of n, by summing
over all pairs of partitions (`clang++ -O3 -std=c++17 gr_fail.cpp -o gr_fail; ./gr_fail N`).
results/gr_fail.txt holds n = 24..44. computations/block_comp.py compares it with the
consecutive-integer obstruction and with (3/4)^n (`python3 block_comp.py ../results/gr_fail.txt`);
computations/block_obstruction.py counts obstructed pairs exactly for small n.

Independent checks: computations/independent/ holds programs that share no code with the ones above.
search.cpp computes Schur coefficients c_lambda(S) by a dynamic programme on Young's lattice
(`clang++ -O3 -std=c++17 search.cpp -o search; ./search N`, or `./search N majorization`), and
verify.py checks its n = 8 output against direct enumeration; outputs for n <= 22 are in
results/independent/. recheck.py (`python3 recheck.py path/to/figs/rowwords.tex`) recomputes every
other number stated in the paper from first principles; gr_check.c (`cc -O3 gr_check.c -o gr_check -lm;
./gr_check N`) rechecks the Remark 3.4 rate numbers using the conjugate form of the dominance test.
