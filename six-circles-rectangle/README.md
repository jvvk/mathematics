A rectangle holds six circles, tangent wherever they look tangent. The segment joining the centres of the two largest circles is exactly as long as the rectangle is high. The note gives a proof using only tangent lengths, the angle bisector theorem, a homothety, equal tangents and isosceles triangles.

The problem is Dan's, from Mathematics Stack Exchange ([question 5112314](https://math.stackexchange.com/q/5112314)) and MathOverflow ([question 515498](https://mathoverflow.net/q/515498)). A longer version of the proof is the author's [MathOverflow answer](https://mathoverflow.net/a/515659), whose figures are in [six-circles-rectangle](https://github.com/jvvk/six-circles-rectangle).

Preprint, 8 October 2026. The author used AI tools in developing this proof and takes full responsibility for its content.

## Contents

- `paper/`: `note.tex` and `note.pdf`. The figures `fig_*.tex` are generated by `verify/gen_figs.py`.
- `verify/`: `config.py` solves the configuration to 50 digits; `check_note.py` checks every claim in the proof (32 checks) and writes `coords.json`; `gen_figs.py` draws the figures from those coordinates.
- `lean/`: the proof formalised step by step in Lean 4 (`SixCircles/Note.lean`), one lemma per argument of the note, chained into the theorem `six_circles_note`. Steps 1 to 3 are stated in coordinates; Step 4 uses the angle sum and the converse of the isosceles triangle theorem in Mathlib's Euclidean plane. It uses only the standard axioms. `mutants.sh` checks that 17 deliberately wrong variants are rejected.

## Reproduce

```
cd verify && python3 check_note.py && python3 gen_figs.py     # needs mpmath
cd ../paper && latexmk -pdf note.tex
cd ../lean && lake exe cache get && lake build                  # Lean 4 and Mathlib, see lean-toolchain
```
