Can a square be cut into rectangles that all have the same perimeter, with no two of them congruent? Yes: an 84 × 84 square can be cut into nine such rectangles, each of perimeter 130. The note proves that nine is the least possible number of pieces, and that up to rotation, reflection and scaling there are exactly five nine-piece dissections, in squares of side 72, 84, 86, 161 and 165. This answers [MathOverflow question 300255](https://mathoverflow.net/q/300255) and refutes a guess of R. Nandakumar ([arXiv:1307.3472](https://arxiv.org/abs/1307.3472), p. 5) that no such square exists.

The proof is an exact enumeration. Equal perimeters turn each combinatorial type of dissection into a square linear system, with one equation per piece, so each type has at most one candidate. Every type with at most nine pieces is listed and solved over the rationals, by two programs that share no code.

Preprint, 8 October 2026. The author used AI tools in developing this work and takes full responsibility for its content.

## Contents

- `paper/`: `note.tex` and `note.pdf`. The figures and the tables (`fig_*.tex`, `intro_list.tex`, `table_all5.tex`) are generated by `verify/gen_figs.py` from `verify/noncongruent_9.json`.
- `verify/`:
  - `floorplans.py` and `exact_all.py` (Program A): generate the mosaic floorplans by top-left insertion (the counts are the Baxter numbers), solve each equal-perimeter system exactly, and count the candidates up to symmetry (the counts match OEIS [A100664](https://oeis.org/A100664)) and the non-congruent ones. The proof of the theorem rests on this program. Output: `output_programA.txt`.
  - `recheck.py` (Program B): an independent recheck that shares no code with Program A. It enumerates tight pavings (the counts match OEIS [A298432](https://oeis.org/A298432)), solves each system by fraction-free elimination, and writes the five solutions to `noncongruent_9.json`. Output: `output_programB.txt`. `mutants.py` checks that four deliberately broken variants of it fail.
  - `check_note.py`: checks the five dissections directly from their integer coordinates (36 checks: each one tiles the square, all perimeters are equal, no two pieces are congruent, coordinates in lowest terms), along with the worked examples in the note. It uses neither enumeration. Output: `output_check_note.txt`.

## Reproduce

Python 3.10 or later, standard library only.

```
cd verify
python3 exact_all.py 9        # Program A, about 25 s
python3 recheck.py 9          # Program B, about 80 s; writes noncongruent_9.json
python3 check_note.py
python3 mutants.py            # about 2 min
python3 gen_figs.py
cd ../paper && latexmk -pdf note.tex
```
