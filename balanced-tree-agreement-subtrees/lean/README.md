# Lean proof sources

Lean 4.34.0; Mathlib is pinned by lake-manifest.json to
5ed2965256430c3649e86755f9576b54eca72435 (v4.34.0).
SOURCE-SNAPSHOT.json records the development commit and the hash of every file. Build caches are excluded.

    lake exe cache get
    lake build LeanProofs
    lake env lean CheckClaims.lean
    python3 scripts/mutants.py

The first command fetches the pinned Mathlib cache, the second compiles the proofs, the third prints the
statements and axioms of the headline results, and the last runs the mutation tests: each plants one wrong
constant, hypothesis or definition and checks that the file no longer compiles.

Agreement is defined through displayed triples (`Tree.Agree`); `agree_iff_restrict_iso` shows that this is
the definition of the paper. `M h` is `M(2^h)`, the least `mast` over balanced phylogenetic trees of height
`h` on a common label set.

The 2048-leaf pair of `Example.lean` is built as in Theorem 4.6 of Bordewich et al.: a template tree of
height 7 carries sixteen 8-caterpillars using all 128 leaves (`catTab`, found by the recursion of their
Lemma 4.3, `../verify/caterpillars.py`), and each cell of the 16 × 16 grid is a caterpillar in one tree and
its reverse in the other. The caterpillar property of the template is checked by evaluation (`catOK`).

Lemma 5.1 is proved by checking a certificate (`certTree`, 1638 integer boxes on the grid `1/2^16`) with
`check`, whose soundness is `check_sound`. The certificate is found by `../verify/cert_one.py`; Lean only
checks it.

Not formalised: the inequality of Lemma 5.3. It enters `ansatz_two` and `M_lower` as the hypothesis
`CertTwo (2/5) (157/2000)`, stated with the 42 strategies `strategies21`; these are generated by
`../verify/gen_strats.py`, which checks that they are exactly the strategies of the certifier, in its order.
The certificate itself (1,418,968 simplices) is checked in exact arithmetic by
`../verify/certify_simplex_rig.py`. Every result uses only propext, Classical.choice and Quot.sound
(axiom-validation.txt). The folder was compiled in an isolated build without the development cache
(build-validation.log).
